# Archive Directory

This directory contains legacy JSON files from the initial development and testing phases of the Steam Config Analyzer project.

## Archived Files

- **`current_shortcuts_updated.json`** - Early test file with R.E.P.O. configuration
- **`shortcuts_config.json`** - Initial shortcuts extraction test
- **`shortcuts_parsed.json`** - Parsed shortcuts data from early development

## Current Active Files

The following files are actively used by the current version of the tool:

- **`all_games_config.json`** - Main output from `extract-all` command
- **`app_name_cache.json`** - Game name resolution cache
- **`backups/`** - Automatic backups of localconfig.vdf

## Migration Notes

These archived files were created during the initial development phase when the tool was focused specifically on shortcuts. The current version extracts all games and supports both sparse and standard modes, making these legacy files obsolete.

The archived files are kept for reference and historical purposes.
